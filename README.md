# UPaaS-QSD-Code

This repository contains supporting resources for the Winter Simulation Conference 2026 paper:

**Unit Process as a Service: A Proposal for Building Resilient European Semiconductor Supply Chains via a Marketplace**

## Repository Overview

The project is organized into two main folders:

### 1. QSD (Qualified Synthetic Data)

Contains the codebase used to generate qualified synthetic semiconductor data.

- Documentation and usage guide: [QSD/README.md](QSD/README.md)

### 2. EDC (Eclipse Dataspace Connector)

Contains artifacts related to data exchange logs produced through the Eclipse Dataspace Connector workflow.

- Documentation and usage guide: [EDC/README.md](EDC/README.md)
